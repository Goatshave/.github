## Editing

Edit the Markdown documents and GitHub issue forms directly. All repository content is written in English.
There is no build step, application runtime, package installation, or deployment workflow.

The official website will be developed separately in its own repository.
Project-specific development, licensing, and release instructions remain in each project's repository.

The operations document is a proposal for discussion. It does not establish organization policy until the decisions and responsible people are recorded.
