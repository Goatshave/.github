# Contributing to Goatshave

Start with a question, a small improvement, or a problem you care about. You can contribute without joining the crew.

## Find a way in

- **Users and visitors:** ask questions, share experiences, or report a reproducible problem.
- **Contributors:** help with code, documentation, tests, design, or translations.
- **Crew and maintainers:** discuss a project role and responsibilities you would like to take on.

Roles and access are agreed separately. Public contributions do not automatically grant organization permissions.

## Make changes together

Read the project's README, contribution guide, and existing discussions. Discuss large changes first and keep each pull request focused.
Explain what changed, why, how you checked it, and any limitations. Include suitable tests for behavior changes and reproducible evidence for performance claims.

Review with specific questions and useful alternatives. Respect different perspectives and leave context for newcomers.
Each project's development, licensing, and release instructions take precedence.

## Start a conversation

[Share a problem or idea](https://github.com/Goatshave/.github/issues/new?template=idea.yml) · [Talk about joining](https://github.com/Goatshave/.github/issues/new?template=crew.yml)

Use the relevant project's issues for its questions and bugs. Crew inquiries can describe your interests and available scope; no resume or legal name is needed.

## Keep participation safe

Respect people. Leave credentials, private data, personal information, and vulnerability details out of public issues.
Use each project's conduct and security reporting routes. [Open Grid's conduct](https://github.com/Goatshave/open-grid/blob/main/CODE_OF_CONDUCT.md) and [security](https://github.com/Goatshave/open-grid/blob/main/SECURITY.md) contacts cover that project only.

Organization-wide reporting contacts and operating responsibilities remain open in the [operations draft](docs/operations-draft.md).
